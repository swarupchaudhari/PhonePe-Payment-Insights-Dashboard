# PhonePe Payment Insights Dashboard

## Project Overview
The PhonePe Payment Insights project analyses digital payment transactions to identify trends in transaction volume, payment value, user activity, and regional performance. Using data analytics and interactive dashboards, the project transforms transaction data into meaningful insights that support better understanding of digital payment behaviour.

## Dashboards

- **Overview Dashboard:** Displays total transaction value, total transaction count, average transaction value, and key performance indicators (KPIs).
- **Transaction Trends Dashboard:** Analyses transaction volume and value over time to identify growth patterns and seasonal trends.
- **State and District Analysis Dashboard:** Compares transaction activity across states and districts to identify high-performing and low-performing regions.
- **Payment Category Dashboard:** Examines transaction distribution across payment types and categories.
- **User Insights Dashboard:** Explores registered users, app usage, and user engagement trends, where user data is available.

## Tools and Technologies
- Power BI
- SQL
- Python (Pandas, NumPy)
- Excel
- Data cleaning, data modelling, DAX, and data visualization

## Key Objectives
- Understand digital payment transaction patterns.
- Identify regional differences in payment activity.
- Track transaction growth and performance over time.
- Present actionable insights through interactive dashboards.

## Project Outcome
The project demonstrates how data analytics and business intelligence tools can convert digital payment data into clear, interactive visual insights.
